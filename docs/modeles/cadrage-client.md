## Premier échange

- Client : particulier ☐ / professionnel ☐ (détermine les conditions générales applicables).
- Activité, objectifs, public visé.
- Besoin : site ☐ / boutique ☐ / identité ☐ / application ☐ / maintenance ☐.
- Contenus disponibles (textes, images, logo) : oui ☐ / non ☐.
- Domaine, hébergement, outils existants, et qui les détient.
- Échéance souhaitée, contraintes, budget envisagé.
- Données personnelles traitées par le futur site ou la future application (rôle de sous-traitant).
